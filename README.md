# MDI Icon Search

[![Buy me a coffee](https://img.shields.io/badge/Buy%20me%20a%20coffee-rein033-FFDD00?logo=buymeacoffee&logoColor=black)](https://buymeacoffee.com/rein033)

Search all 7,400+ Material Design Icons used by Home Assistant, by name, alias, tag or even in Dutch. Click to copy mdi:name, YAML or the SVG.

**Use it:** [uselesssite.nl/mdi-icon-search](https://uselesssite.nl/mdi-icon-search/)

- Search 7,400+ icons by name, alias and category, instantly
- Dutch search words work too (lamp, deur, wasmachine, …)
- Preview in your own colour and size, light or dark
- Copy `mdi:name`, a YAML `icon:` line, the SVG or the path data
- Browse by category, recently copied icons are remembered
- Deep links: `#lightbulb` opens that icon directly

Everything runs in your browser; the icon list is loaded from the jsDelivr CDN.

Part of the free, open-source tools at [uselesssite.nl/tools](https://uselesssite.nl/tools/).

## Development

Plain HTML, CSS and JavaScript, no build step. Open `index.html` through any static web server.
`base.css` and `base.js` are shared with the other tools; the tool itself lives in `app.js` and `style.css`.
